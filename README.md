# Assignment 5 - JavaScript Basics

Open `index.html` in a browser to access all three tasks. No libraries, frameworks, or inline event handlers are used.

## Included tasks

1. `task1-battle.html` / `task1-battle.js` - a turn-based battle with random damage, defense, healing, critical hits, five-item action log, end state, and restart.
2. `task2-kanban.html` / `task2-kanban.js` - a Kanban board built from 10 data objects. It provides search, tag filtering, sorting, a loop-calculated completion value, event delegation, and a three-card column limit.
3. `task3-ticket.html` / `task3-ticket.js` - a ticket builder with seven fields, live preview, custom validation after blur, an error summary, focus management, confirmation code, and reset.
